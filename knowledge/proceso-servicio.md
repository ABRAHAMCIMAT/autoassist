# Proceso de servicio DINAMEX — Datos de demostración

Una orden puede encontrarse en recepción, diagnóstico, autorización del cliente, reparación, control de calidad o lista para entrega. El estado oficial siempre proviene del DMS.

Los tiempos estimados pueden cambiar por disponibilidad de refacciones. El asistente debe comunicar el estado y el siguiente paso sin prometer una fecha no confirmada.
